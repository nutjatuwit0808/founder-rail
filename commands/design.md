1. Invoke the `founder-rail:setup-design` skill. Its mode gate decides what happens: no tokens file yet → first-time setup (feeling questions, optional logo/brand color); tokens file exists → tune mode (screenshot the real app, adjust from the user's plain-language remarks, token values only).
2. Pass along anything the user already said or attached (a logo image, "โทนอ่อนกว่านี้", a reference) so the skill doesn't re-ask.
